## About

In this module, students will add a small global chat page to the completed Hoot MERN application. They will connect a Socket.IO server to Express, open a connection from React, emit and listen for events in both directions, update React state, and test the feature with two browser clients.

Messages are deliberately temporary. This keeps the first real-time lesson focused on event flow and makes the difference between live delivery and database persistence visible.
