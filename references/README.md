## Quick vocabulary

| Term | Meaning in this lesson |
| --- | --- |
| Connection | The continuing communication link between one browser and Socket.IO. |
| Socket | One endpoint of a connection. |
| Event | A named message with optional data. |
| `emit` | Send an event. |
| `on` | Register a listener that runs when an event arrives. |
| Broadcast | Send an event to multiple connected clients. |
| Handshake | The initial exchange used to establish the connection. |
| Transport | The lower-level method used to move data, such as WebSocket or HTTP long-polling. |
| Persistence | Saving data so it can be retrieved after a refresh or reconnection. |
