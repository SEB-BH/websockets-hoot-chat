## Version 1.0

### Additions

- Added a beginner Socket.IO chat feature for the completed Hoot MERN application.
- Added granular checks for server setup, connection lifecycle, both event directions, React state, multiple clients, WebSocket frames, reconnection, and persistence boundaries.
- Added an instructor guide, final-code reference, troubleshooting table, and separated level-ups.

### Teaching conventions

- Uses explicit code and named callback functions.
- Uses `user` props rather than React context.
- Keeps the initial event handler in `server.js`.
- Keeps the MVP global, temporary, and intentionally unauthenticated at the socket layer.
